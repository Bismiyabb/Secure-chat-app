# Secure Chat Application

A multi-user chat app in Python with a Tkinter GUI, TCP sockets, and Fernet (symmetric) encryption.

## How it works
- `server.py` accepts many clients (one thread each) and broadcasts messages.
- `client.py` is the Tkinter GUI; a background thread receives, a queue hands messages to the UI thread.
- `common.py` holds the shared protocol: each message is JSON -> Fernet-encrypted -> sent with a 4-byte length prefix (so TCP stream boundaries are handled correctly).
- Server and clients share one secret key (`secret.key`), generated by the server on first run.

## Run
```
pip install cryptography
python server.py            # creates secret.key
# copy secret.key into the client's folder (same folder on one PC)
python client.py            # run in 2+ terminals
```
Tkinter ships with Python (on Linux: `sudo apt install python3-tk`).

## Limitations (good to mention in interviews)
- Pre-shared symmetric key: no key exchange. A real system would use RSA/ECDH or TLS.
- No user authentication or message history.
- Fernet gives confidentiality + integrity, but not forward secrecy.
